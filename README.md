## Open Source

**[task-bridge](https://github.com/Jotto1988/task-bridge)**  
An open protocol proposal for routing AI-displaced work back to humans — a structured handoff layer between AI agents and skilled human workers. A call to Anthropic, OpenAI, Google DeepMind, and the developer community to build a standard that creates human work rather than eliminating it.
